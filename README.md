### Perfil Profesional

Desarrolladora de software con formación integral en **Pedagogía y Tecnologías de la Información**. Experiencia en el diseño e implementación de aplicaciones web interactivas, arquitecturas cliente-servidor, desarrollo de APIs RESTful seguras, modelado de bases de datos relacionales y NoSQL, y contenedores con Docker.

Combino el rigor técnico de la ingeniería de software con principios pedagógicos para construir plataformas digitales orientadas a la resolución de problemas, el aprendizaje interactivo y la optimización de procesos.
